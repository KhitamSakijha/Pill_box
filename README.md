# Pill Box 💊

A smart medication management system built with Flutter & Firebase, designed to help users organize their medicines, track doses, and improve medication adherence through an intuitive mobile application.
---

## 📌 Overview
This project is a Smart Pill Box application that allows users to manage their medications digitally. It provides scheduling, reminders, and tracking features to ensure users take the right medicine at the right time. The system is integrated with Firebase for secure cloud data storage and synchronization across devices.

---

## ✨ Features
* **User Authentication:** Secure login and registration using Firebase Authentication.
* **Medicine Management:** Add, edit, and delete medications with full details (dose, frequency, notes, and schedule).
* **Smart Scheduling:** Set multiple daily times for medication intake with flexible frequency options (Daily, Weekly, Monthly, As Needed).
* **Adherence Tracking:** Monitor medication history and track whether doses were taken.
* **Profile Management:** Update personal information such as weight, height, blood type, and date of birth.
* **Cloud Sync:** All data is stored and synchronized using Firebase Firestore.
* **User-Friendly UI:** Clean and modern interface designed for easy navigation.

---

## 🛠 Tech Stack

* **Frontend: Flutter (Dart)**
* **Backend: Firebase (Authentication & Firestore)**
* **State Management: Stateful Widgets / Local State**
* **Architecture: Modular UI Screens (Separation of concerns)**
* **Data Handling: Firestore CRUD operations**
* **Time Management: DateTime & TimeOfDay for scheduling doses**

## 🚀 How to Run

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/khitamSakijha/Pill_Box.git
    ```

2.  **Navigate to the project folder:**
    ```bash
    cd Pill_Box
    ```
3.  **Install dependencies:**
    ```bash
     flutter pub get
    ```
4.  **Run the application:**
    ```bash
    flutter run
    ```
